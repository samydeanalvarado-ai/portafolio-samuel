## Descripción
Portafolio académico que presenta mi perfil, habilidades en formación y proyectos académicos y personales: TaskManager, SELAH y este portafolio. Cuenta con navegación interna, avatar representativo, diseño adaptable y un formulario visual.

## Tecnologías
- HTML5: estructura semántica, enlaces, imágenes y formularios.
- CSS3: variables en `:root`, Flexbox, Grid, media queries y estados `:hover`.
- Git y GitHub: historial de desarrollo y alojamiento del repositorio.

## Cómo visualizar el proyecto
1. Descarga o clona el repositorio.
2. Abre `index.html` en tu navegador.
3. Usa el menú para navegar por las secciones.

No requiere instalaciones, servidor, dependencias ni conexión a Internet para visualizar el contenido local. Los enlaces a GitHub sí requieren conexión.

## Archivos
- `index.html`: contenido y estructura semántica.
- `styles.css`: todos los estilos y adaptaciones para móviles.
- `img/`: avatar e ilustraciones SVG originales y representativas; no son capturas de los proyectos.

## Formulario
El formulario valida nombre, correo y mensaje mediante HTML. Al pulsar «Enviar mensaje» muestra un aviso de demostración mediante CSS `:target`. No envía ni almacena información; los campos no tienen atributo `name` para evitar incluir sus valores en la URL.

## Historial
El desarrollo se divide en cinco cambios funcionales: estructura inicial; navegación y presentación; sobre mí y habilidades; proyectos y contacto; estilos finales y documentación. Los commits se realizaron durante la preparación del proyecto con asistencia de IA y sin alterar sus fechas. El estudiante debe revisar, comprender y personalizar el código antes de entregarlo y declarar la asistencia si su curso lo requiere.
